# Ponytail Skill Guidelines
1. Always use modern Tailwind CSS utility classes; avoid inline styles and custom raw CSS.
2. Focus on clean, responsive, mobile-first design with good contrast and accessible typography.
3. Keep UI minimal and lightweight (Green IT & Low-bandwidth UI principles).
4. When writing React components, ensure full compatibility with Inertia.js props.
