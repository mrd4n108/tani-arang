# Green IT Principles
1. Compress uploaded images on the client side using HTML Canvas (< 300KB) before submitting to backend.
2. Maintain clean, lightweight Tailwind UI without heavy animations or unnecessary libraries.
3. Keep server roundtrips minimal and show execution latency or efficiency badges where appropriate.
